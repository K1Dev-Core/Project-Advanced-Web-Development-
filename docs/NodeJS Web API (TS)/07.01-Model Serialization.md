# การแปลงข้อมูลและโมเดล (Model & Serialization)

## 1. JSON และ Object ต่างกันอย่างไร?
- **JSON (JavaScript Object Notation):** รูปแบบข้อความสากลที่ใช้ส่งหากันข้ามภาษาคอมพิวเตอร์ทั่วไป
- **TypeScript/JS Object:** วัตถุที่สร้างขึ้นและใช้ประมวลผลอยู่ภายในหน่วยความจำของแอปพลิเคชันเรา

---

## 2. Serialization และ Model
- **Serialization (การแปลงรูป):** ขบวนการแปลงวัตถุ (Object) ไปมาระหว่างข้อความ JSON หรือข้อมูลดิบจากฐานข้อมูล
- **Model:** ตัวกำหนดโครงสร้าง (Interface) เพื่อระบุอย่างชัดเจนว่าข้อมูลในระบบเราต้องมีคีย์และประเภทข้อมูลอะไรบ้าง ป้องกันการป้อนข้อมูลผิดพลาด

![[Pasted image 20250616233755.png]]

สร้างโมเดลสำหรับทริปการท่องเที่ยว:
`model/trip.ts`
```ts
export interface Trip {
    idx:           number;
    name:          string;
    country:       string;
    destinationid: number;
    coverimage:    string;
    detail:        string;
    price:         number;
    duration:      number;
} 
```

> [!TIP]
> **เครื่องมือช่วยแปลงสุดเทพ:** สามารถใช้เว็บไซต์ [QuickType.io](https://quicktype.io/) เพื่อวางตัวอย่าง JSON แล้วแปลงออกมาเป็น Interface ในภาษา TypeScript ให้เลยอัตโนมัติ สะดวกมาก!

## 3. การกำหนดประเภทข้อมูล (As Type)
ตอนที่เราดึงข้อมูลดิบมาจากคิวรีในฐานข้อมูล ตัวแปรมักจะเป็นประเภท generic (`any` หรือ `RowDataPacket[]`) เราควรใช้คำสั่ง `as` เพื่อระบุชนิดข้อมูลให้ชัดเจนตามโมเดลของเรา เพื่อความง่ายในการดึงคีย์ต่างๆ ไปใช้งานต่อ:

`controller/trip.ts`
```ts
import { Trip } from "../model/trip";

//...

router.get("/", async (req, res) => {
  const [rows] = await conn.query("SELECT * FROM trip");
  let trips = rows as Trip[];
  res.json(trips);
});
```
