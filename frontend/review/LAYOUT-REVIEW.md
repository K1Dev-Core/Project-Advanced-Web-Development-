# ตรวจและปรับ UX/UI ทุกหน้า — 15 ตุลาคม 2026

## หน้าที่ตรวจ

ตรวจหน้าลูกค้า, ติดตามแบบยังไม่กรอกรหัส, ติดตามพัสดุจริง, login, เปิดใบงานไรเดอร์, ใบงานไรเดอร์, dashboard, พัสดุ, ลูกค้า, ไรเดอร์, แผนส่ง และตั้งค่าบริการ รวมถึงฟอร์มพัสดุ/ลูกค้า/ไรเดอร์ และหน้าต่างรายละเอียดพัสดุ

แต่ละหน้าและสถานะตรวจที่ **320, 390, 768, 1024 และ 1440 พิกเซล** รวม 80 มุมมองต่อรอบ เก็บภาพก่อนและหลังพร้อมข้อมูลขนาดจริงจาก DOM มีภาพเต็มหน้าสำหรับมือถือและเดสก์ท็อปเพิ่มเติมเพื่อดูส่วนท้ายของหน้า

## สิ่งที่แก้

- สร้างระบบแนวจัดวางร่วมใน `src/app/styles.css`: ขอบเนื้อหาเดียวกัน, header/action row, spacing, padding, ขนาดปุ่มและช่องกรอกที่สม่ำเสมอ
- แก้ input ประเภทเวลาและตัวเลขที่สูงต่างกัน 2 พิกเซล ให้ตรงกันจริง รวมชื่อ/นามสกุล และละติจูด/ลองจิจูดในฟอร์ม
- ฟอร์มยาวมีปุ่มบันทึก/ยกเลิกติดด้านล่าง มองเห็นได้ตั้งแต่เปิด dialog และเมื่อเลื่อนหน้าฟอร์ม ยังคงกด Enter เพื่อบันทึกได้
- ปรับความสูงหัวข้อและตำแหน่ง action ของการ์ดลูกค้า/ไรเดอร์/เส้นทางให้เป็นแนวเดียวกัน
- ปรับหน้า login ให้มีหัวข้อหลักที่มองเห็นบนมือถือ จัด input และปุ่ม login ให้ขอบและความกว้างตรงกัน
- ปรับแถวปุ่มค้นหา ตัวกรอง วันจัดส่ง ปุ่มเพิ่ม และตัวเลือกแผน ให้ไม่เบียดกันบนจอเล็ก
- จัดหน้าลูกค้าบนมือถือให้ช่องติดตามอยู่ก่อนเนื้อหารอง ลดการเลื่อนเพื่อเข้าถึงงานหลัก
- ปรับ sidebar ให้เลื่อนได้บนจอแนวนอนเตี้ย และขนาดเมนูมือถือ/พื้นที่ด้านล่างให้รองรับ safe area
- ยกเลิกการเอียงของป้าย/ภาพประกอบตกแต่งที่ทำให้แนวหน้าดูไม่สม่ำเสมอ
- ลบ style เดิมที่ถูกแทนและไอคอนที่ไม่ใช้ เพื่อให้ build ยังอยู่ในขนาดที่กำหนด

## ผลตรวจ

- ข้อมูลขนาด DOM หลังแก้: ไม่พบ document overflow แนวนอน, องค์ประกอบที่ตรวจล้นขอบจอ หรือข้อความเมนูมือถือกว้างเกินช่อง ใน 80 มุมมอง
- ตรวจภาพจริงทั้งส่วนบนและส่วนท้ายของหน้า รวมฟอร์มยาวและการ์ดหลายแถว
- UI/API contract/layout regression: **23/23 ผ่าน**
- Build production และ TypeScript: ผ่าน
- ทดสอบการทำงานจริงกับ Express + MySQL หลังปรับ: **ผ่าน** (เพิ่มลูกค้า/พัสดุ → เส้นทางถนนจริง → ไรเดอร์ส่งสำเร็จ → หน้าติดตามอัปเดต)
- ไม่มี browser runtime error ระหว่างเก็บภาพ

## ดูหลักฐานในเครื่อง

- `layout-before/` — ภาพก่อนแก้
- `layout-after/` — ภาพหลังแก้และภาพเต็มหน้า
- `layout-after/metrics.json` — รายงานขนาด/overflow
- `layout-preview.png` — ตัวอย่างหน้ามือถือหลังแก้

ชุดภาพ audit จำนวนมากถูก exclude จาก Git แต่เก็บอยู่ใน workspace นี้ สร้างซ้ำได้ด้วย `node scripts/audit-layout.mjs after` จาก `frontend/` ขณะระบบในเครื่องทำงาน
