# Web API (5 คะแนน)

สร้าง Web API ข้อมูลโปรเจ็ควิชา
1. ER Diagram โดยสร้างจากเวบ https://erdplus.com/
2. Web API สำหรับจัดการลูกค้า
	1. เพิ่ม ลบ แก้ไข แสดงข้อมูลทุกคน
	2. ค้นหาจากส่วนหนึ่งของชื่อ, นามสกุล
	3. ค้นลูกค้าทั้งหมดในระยะ 1 กิโลเมตร จากพิกัดที่กำหนด
3. Web API สำหรับจัดการรายการสั่งซื้อ
	1. จำลองรายการสั่งซื้อได้ 20-30 รายการ โดยมีข้อมูลครบถ้วน
		1. ข้อมูลลูกค้าที่สั่ง
		2. จำนวนกล่องที่สั่งซื้อในแต่ละ ออร์เดอร์
		3. เพิ่ม ลบ แก้ไขจำนวนกล่อง ได้
	2. ล้าง(ลบทั้งหมด) รายการสั่งซื้อที่จำลองทั้งหมดได้
	3. แสดงรายการสั่งซื้อทั้งหมดในระยะ 2 กิโลเมตร จากพิกัดที่กำหนด
4. Deploy บน Server ให้อาจารย์/TA ทดสอบได้จากอินเทอร์เน็ต
