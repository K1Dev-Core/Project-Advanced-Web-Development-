# ข้าวกล่อง — brand assets

`khaokong-logo.png` คือโลโก้ที่ผู้ใช้ส่งมา ใช้ไฟล์ต้นฉบับโดยไม่แก้ภาพและคงพื้นหลังโปร่งใส ใช้ในหัวเว็บ หน้าเข้าสู่ระบบ และ favicon

ภาพมีสัดส่วน 4:3 จึงแสดงแบบ object-fit: contain ขนาด 76×57 px บนหัวเว็บ, 64×48 px บนมือถือ และ 112×84 px บนหน้าเข้าสู่ระบบ ชื่อร้านยังเป็นข้อความ HTML เพื่อให้อ่านได้ชัดและรองรับ screen reader

`khaokong-logo.svg` เก็บเป็นแบบก่อนหน้า ไม่ได้ใช้ในหน้าจอปัจจุบัน
